# Validation evidence (simple checks)

Agreed for now: simple screenshots per onboarded application. Full-fledged SIT is completed later and is not covered here.

For each application, in the target tenant (sandbox first, then production), capture and attach to the change record:

- [ ] Run reference: workflow run link and the `onboarding-report` status for the app (`ok`).
- [ ] **Account provisioning**: the Activity section shows the aggregation / account provisioning as completed.
- [ ] **Account correlation**: in the identity cube of a sample identity (the pilot app's test user), the account appears under the identity, i.e. it correlated.
- [ ] Each screenshot shows the application name, the tenant, and the date/time.
- [ ] For wave runs: wave 1 (pilot app) evidence reviewed before wave 2 is started.
